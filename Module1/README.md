## 🚀 How to Use the Notebooks

1. Open the `project-Notebooks` folder.
2. Select the `.ipynb` notebook you want to use.
3. Download the notebook.
4. Open [Google Colab](https://colab.research.google.com/).
5. Upload the downloaded notebook.
6. Download the required dataset from the `datasets` folder.
7. Upload the dataset to Colab.
8. Connect to the runtime.
9. Run the notebook cells and follow the practical steps.

## ⚠️ Important

Some notebooks require a specific dataset to run properly.

Before running a notebook, check the `datasets` folder and make sure the required dataset is available.
